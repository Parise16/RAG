# Base de conhecimento

Esta pasta reúne os arquivos portáveis do assistente:

| Arquivo | Função |
| --- | --- |
| `documentacao.md` | Conhecimento do negócio; cada seção `##` é um trecho recuperável. |
| `comportamento.md` | Instruções carregadas na mensagem de sistema. Não é indexado como conhecimento. |
| `avaliacao.md` | Casos para conferir respostas e limites. Não é indexado. |

Para usar em uma plataforma de assistentes, envie `documentacao.md` como conhecimento e copie `comportamento.md` para o campo de instruções. Apenas publicar Markdown no GitHub não executa RAG: é necessário um sistema que indexe e recupere o conteúdo.

As políticas e os contatos são dados fictícios de demonstração, provenientes do exercício original. Não são canais reais de atendimento. A documentação não define arredondamento de quilômetros adicionais, composição do valor para frete grátis ou todas as combinações de cancelamento: não presuma essas regras.
