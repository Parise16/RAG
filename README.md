# RAG — IA aplicada

Projetos de estudo sobre geração aumentada por recuperação (Retrieval-Augmented Generation), modelos de linguagem e assistentes virtuais.

## Projetos

🍔 **[RangoJá](RangoJá/README.md)** — assistente de atendimento para um app fictício de delivery. Combina busca semântica, modelos locais e uma base de conhecimento em Markdown.

O projeto demonstra o fluxo completo: documentação → divisão em trechos → embeddings → recuperação → contexto → resposta.
